# Emoji Movie Guessing Game

A fun, interactive web game where players guess movie titles based on emoji representations. 

## How to Play

1. A movie will be represented by emojis
2. Use keyboard to guess letters
3. You have 5 tries to guess the movie correctly
4. Score is calculated based on remaining tries:
   - Each remaining try = 100 points
   - Maximum points per level = 500 (5 tries × 100)
5. Try to achieve the highest score possible!
